# Privacy Policy

The Gold- und Silberrechner does not collect, store or transmit personal user data.

The application connects automatically to the project server at:

https://gsr.linuga.org/

This connection is used exclusively to retrieve current gold and silver prices required for the application's intended functionality.

As with any normal HTTPS connection, the server may receive technical connection data such as the client's IP address as part of the network communication.

No advertising, analytics or user tracking is integrated into the application.
